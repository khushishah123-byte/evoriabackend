## Why This Migration?

### Benefits of Firebase over MongoDB

| Feature | MongoDB | Firebase | Benefit |
|---------|---------|----------|---------|
| Real-time Sync | Manual polling | Built-in listeners | Better performance |
| Auth Management | Manual JWT | Built-in Firebase Auth | More secure |
| Hosting | Need separate server | Can host on Firebase | Easier deployment |
| Scalability | Manual scaling | Auto-scaling | Better for growth |
| Cost | Pay per instance | Pay per usage | Cost-effective |
| Security | Manual setup | Best practices built-in | More secure |

## Data Structure Changes

### Users Collection

**MongoDB** (Mongoose):
```javascript
{
  _id: ObjectId,
  email: "user@example.com",
  password: "hashed_password",
  username: "john_doe",
  phone: "1234567890",
  address: "123 Main St",
  role: "user",
  createdAt: Date,
  updatedAt: Date
}
```

**Firebase Firestore**:
```javascript
users/{userId}
{
  id: "firebase_uid",  // Auto-generated by Firebase Auth
  email: "user@example.com",
  // password stored in Firebase Auth (not in DB)
  username: "john_doe",
  phoneNumber: "1234567890",
  address: "123 Main St",
  role: "user",
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

**Key Changes**:
- Password managed by Firebase Auth (not stored in DB)
- ID uses Firebase UID (security best practice)
- Field renamed: `phone` → `phoneNumber`
- Timestamps are Firebase Timestamp objects

## Query Examples

### User Registration

**MongoDB (Mongoose)**:
```javascript
const user = await User.create({
  email,
  password: hashedPassword,
  username,
  phone,
  address,
  role: "user"
});
```

**Firebase Firestore**:
```javascript
// 1. Create Firebase Auth user
const firebaseUser = await auth.createUser({
  email,
  password,
  displayName: username
});

// 2. Create Firestore user document
await db.collection("users").doc(firebaseUser.uid).set({
  username,
  email,
  phoneNumber: phone,
  address,
  role: "user",
  createdAt: new Date(),
  updatedAt: new Date()
});
```

### Find User by Email

**MongoDB (Mongoose)**:
```javascript
const user = await User.findOne({ email });
```

**Firebase Firestore**:
```javascript
const snapshot = await db.collection("users")
  .where("email", "==", email)
  .limit(1)
  .get();

const user = snapshot.docs[0]?.data();
```

### Update User

**MongoDB (Mongoose)**:
```javascript
await User.updateOne(
  { _id: userId },
  { $set: { username, phone, address } }
);
```

**Firebase Firestore**:
```javascript
await db.collection("users").doc(userId).update({
  username,
  phoneNumber: phone,
  address,
  updatedAt: new Date()
});
```

### Delete User

**MongoDB (Mongoose)**:
```javascript
await User.deleteOne({ _id: userId });
```

**Firebase Firestore**:
```javascript
// 1. Delete from Firestore
await db.collection("users").doc(userId).delete();

// 2. Delete from Firebase Auth
await auth.deleteUser(userId);
```

## Authentication Flow Changes

### Before (MongoDB + JWT)

```
1. User posts email/password to /signin
2. Backend queries MongoDB for user by email
3. Compare password hash
4. Generate JWT token (custom implementation)
5. Return token to client
6. Client sends JWT in Authorization header for future requests
7. Backend verifies JWT manually
```

### After (Firebase)

```
1. User posts email/password to /signin
2. Backend calls Firebase REST API: signInWithPassword
3. Firebase verifies credentials and returns ID token
4. Store user data in Firestore
5. Return ID token to client
6. Client sends ID token in Authorization header
7. Backend verifies with: await auth.verifyIdToken(token)
```

## Real-time Capabilities (New!)

Firebase enables real-time updates that weren't available with MongoDB:

```javascript
// Real-time listener for user changes
db.collection("users").doc(userId).onSnapshot((doc) => {
  console.log("User updated:", doc.data());
});

// Real-time listener for all events
db.collection("events").onSnapshot((snapshot) => {
  snapshot.docChanges().forEach((change) => {
    if (change.type === "added") {
      console.log("New event:", change.doc.data());
    }
    if (change.type === "modified") {
      console.log("Event updated:", change.doc.data());
    }
    if (change.type === "removed") {
      console.log("Event deleted:", change.doc.id);
    }
  });
});
```

- MongoDB: Manual scaling required

- MongoDB: Manual caching implementation
- Firebase: Built-in caching for offline support
